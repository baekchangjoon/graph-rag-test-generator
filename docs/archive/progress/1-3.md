# 1.3 — MyBatis XML mapper 인덱서

## 진행 내용

- `MapperXmlIndexer`: mapper XML DOM 파싱 → `MapperStatement`(namespace,
  statementId, sqlKind, dynamic 여부, 원문 XML). 동적 태그(if/choose/foreach/
  where/set/trim/bind) 탐지. 외부 DTD 로드 차단 (오프라인/보안)
- SUT 확장: order-service에 MyBatis 혼재 — `POST /api/orders/search`
  (`<if>` 동적 SQL 3분기 + 빈 필터 400)

## 검수

- 인덱서 단위 테스트 2건, SUT 테스트 3건 (동적 조건 조합), 빌더 통합에서
  graph.json `mappers`에 search statement 수록 확인
