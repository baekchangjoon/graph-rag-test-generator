# 2.1/2.2 — 외부 HTTP 호출 추적 + 임베디드 WireMock

## 진행 내용

- 분석 환경에 임베디드 WireMock(`HttpCaptureServer`) 추가. SUT의 외부 URL은
  `--sut-env KEY={{wiremock}}` 치환으로 redirect (env 주입 원칙 유지)
- 외부 시스템의 minimal valid 응답은 운영자가 `--external-stubs <dir>`
  (WireMock mapping JSON)로 제공 — docs/03의 전제 그대로
- 요청 단위 journal delta → `CapturedHttpCall`(method/urlPath/query/요청·응답 body)
- SUT 확장: EXPRESS 주문 → `GET /inventory/stock` (RestTemplate), 재고 부족 409
- 정적 dataflow 기반 URL/body 추적(원안 2.1)은 보류 — 실행 캡처가 같은 사실을
  더 정확히 제공 (`docs/decisions/http-capture.md`)
- 탐색 보강: handler의 enum-스타일 리터럴 변이(EXPRESS 도달) + large 값 변이
  (409 도달) + 퍼저 포화를 "시드 패스" 단위로 개선, 2xx 시드 우선

## 검수

- 실 SUT 통합: EXPRESS 201(heuristic·literal 변이) / 409(fuzzer·large 변이 2단
  조합) path 발견, CapturedHttpCall 캡처 검증
