# 0.6 — graph-rag-builder

## 진행 내용

- 7a `EndpointIndexer`: Spoon noClasspath. @RestController/@PostMapping/@RequestBody
  → Endpoint + BodyShape(레코드 컴포넌트/필드)
- 7b `GraphStore` 인터페이스 + `JsonFileGraphStore` (graph.json)
- 7c `AnalysisEnvironment`(Testcontainers Postgres) + `SutProcess`(운영 jar 자식
  프로세스, env 주입, health 폴링, stdout 파일 캡처 + 오프셋 마커)
- 7d `HibernateSqlLogParser`: org.hibernate.SQL + org.hibernate.orm.jdbc.bind
  로그 → ParsedSql(컬럼 매핑 best-effort)
- 7e `SchemaExtractor`: DatabaseMetaData → Table/Column/FK/UNIQUE
- 7f `SampleInputSynthesizer`(FK 휴리스틱 + 결정적 값) + `PathCaptureRunner`
  (seed INSERT → 캡처 → origin 판정)
- 7g `BuilderCli`: `build --sut-src --sut-jar --out [--sut-id --commit-sha --postgres-image]`
