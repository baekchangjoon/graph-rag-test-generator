# 0.4 — test-state-dashboard

## 진행 내용

- Spring Boot 단일 앱: `POST /events`(202) + `GET /active` / `/leaked` / `/test/{id}`
- `TestRunStore`: in-memory, 이벤트 → TestRun 상태 머신 (ACTIVE/CLEANED/LEAKED).
  SCOPE_CREATED 없이 자원 이벤트가 먼저 와도 방어적으로 추적 (이벤트 손실 대비)
- `LeakDetector`: 주입된 시각 기준 TTL(기본 300s) 스캔, `@Scheduled`(30s) 래퍼
- Dockerfile (`bootJar` 산출물 기반)

## 검수

- `./gradlew :test-state-dashboard:test` GREEN (store 4건 + leak 3건 + API 1건)

## 설계 부합 / 메모

- Reaper, Slack 알람, 영속화(SQLite/PG), reconciliation은 docs/08에서 옵션 —
  Phase 0 범위 외로 보류. 누수 알람은 콘솔 로그(WARN)만.
- `GET /tables/{name}/holders`, `GET /history`는 Phase 0 미사용으로 보류.
