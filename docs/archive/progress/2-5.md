# 2.5 — 응답 필드 사용 추적

## 진행 내용

- `ResponseDtoIndexer`: SUT 소스에서 RestTemplate류 호출의 응답 DTO 타입 필드를
  정적 수집 (getForObject(.., X.class)의 X)
- 캡처 응답의 top-level 필드 ∩ DTO 필드 → `CapturedHttpCall.consumedFields`
- 스텁 응답 body는 consumedFields만 투영 (스텁이 캡처 응답 전체에 과적합되는
  것을 방지 — "소비자가 읽는 필드만 mock")

## 검수

- 실 SUT: consumedFields=[available]. 생성 스텁에서 미사용 필드 제외 검증
  (fixture의 warehouse 필드 투영 제거 단위 테스트)

## 한계 (정직하게)

- "DTO 바인딩 필드"는 실제 읽은 필드의 상한 근사. 콜그래프 기반 정밀 추적은
  보류 (`docs/decisions/http-capture.md`)
