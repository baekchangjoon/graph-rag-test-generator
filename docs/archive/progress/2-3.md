# 2.3 — OTEL javaagent (분석 + 테스트 양쪽)

## 진행 내용

- OTEL javaagent를 Gradle 의존성으로 번들(`OtelAgent`, 런타임 다운로드 없음)
- 분석 환경: jacoco + otel 이중 javaagent를 `JAVA_TOOL_OPTIONS`로 부착,
  `OTEL_*` env (exporter 전부 none, propagators=tracecontext,baggage)
- invoker가 요청마다 `baggage: test-id=...` 주입 → WireMock 수신 헤더로
  **전파를 실측** → `CapturedHttpCall.baggagePropagated`
- 테스트 실행 환경: compose의 app 컨테이너에 동일 agent(volume) + env (docs/06)

## 검수

- 실 SUT 통합: baggagePropagated=true 실측 (Spring RestTemplate에 OTEL이
  inbound baggage를 outbound로 복사함을 확인)
