# 0.1 — 프로젝트 골격

## 진행 내용

- Gradle 8.14.3 wrapper (글로벌 Gradle 9.5는 Spring Boot 플러그인 호환성 미검증이라 미사용)
- Java 17 toolchain (corretto-17.0.18), `gradle.properties`에 java.home 고정
- version catalog (`gradle/libs.versions.toml`)로 의존성 버전 단일화
- 모듈 8개: shared-model, testlib, test-state-dashboard, socket-mock-server,
  graph-rag-builder, test-generator, samples:order-service, e2e
- 루트에서 JUnit 5 platform + 테스트 로깅 공통 설정

## 검수

- `./gradlew build` → BUILD SUCCESSFUL (전 모듈)

## 설계 부합

- spec의 리포 구성과 일치. CI 골격은 원격 리포 부재로 보류
  (로컬 `./gradlew check`로 대체, 원격 push 시점에 GitHub Actions 추가 예정).
