# 3.1 — WsEndpoint 인덱싱

- `WsEndpointIndexer`: Spoon으로 `@MessageMapping`/`@SendTo` + payload BodyShape
  (HTTP 인덱서와 `BodyShapeExtractor` 공용화) + WS 설정 리터럴(`/ws`, `/app`) 추출
- SUT 확장: `/app/orders/count` → `/topic/orders` (payload `{userId}` → `{userId,count}`,
  JPA 파생 쿼리)
- 검수: 인덱서 단위 2건 + SUT STOMP 클라이언트 테스트 GREEN
