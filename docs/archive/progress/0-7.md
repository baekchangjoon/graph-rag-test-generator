# 0.7 — test-generator

## 진행 내용

- `GraphRagClient` 인터페이스 + `FileGraphRagClient`(graph.json 조회, fail-fast)
- `FixtureComposer`: 치환/픽스처/cleanup/body/assertion 슬롯 합성 (규칙은
  `docs/decisions/generator-composition-rules.md`)
- `Generator`: Mustache 템플릿 + 슬롯 → RestAssured 테스트 `.java` +
  `GenerationResult`(parallel safety 포함)
- `GeneratorCli`: `generate --request --graph --out` → `.java` + `generation-result.json`

## 검수

- `./gradlew :test-generator:test` GREEN 10건
  - 골든 파일 정확 일치 (생성 코드 전문 고정)
  - 결정성: 같은 입력 2회 → 동일 결과
- 트러블슈팅: Mustache 인라인 섹션이 줄바꿈을 삼키는 문제 → assertion 블록을
  composer에서 사전 렌더링
