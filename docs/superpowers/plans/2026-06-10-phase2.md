# Phase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. 단계별 TDD + commit + progress 기록.

**Goal:** 외부 HTTP 의존 endpoint의 테스트를 WireMock + OTEL baggage 격리로 생성·통과.

**Spec:** `docs/superpowers/specs/2026-06-10-phase2-design.md`

### Task A: shared-model — CapturedHttpCall / capturedHttpCallIds / httpCalls
라운드트립 + 후방 호환 테스트 → commit

### Task B: SUT — inventory 외부 호출
- `InventoryClient`(RestTemplate, env `EXTERNAL_INVENTORY_URL`) + EXPRESS/409 분기
- SUT 테스트: 로컬 HttpServer 스텁으로 201(재고충분)/409(부족) 검증 → commit

### Task C: builder — literal 후보 변이 + large 값 변이
- `LiteralCandidateExtractor`(Spoon, enum-스타일 리터럴) → EndpointTarget.literals
- InputMutator: `literal-<field>-<value>`, `large-<field>`(1_000_000) 추가
- 단위 테스트 (fake invoker로 EXPRESS/409 도달) → commit

### Task D: builder — 임베디드 WireMock + OTEL + http 캡처
- 의존성: org.wiremock:wiremock, otel agent jar(Gradle configuration)
- AnalysisEnvironment: WireMockServer + `--external-stubs` 로드 + `--sut-env` 치환
- SutProcess: 다중 javaagent + OTEL env
- invoker: 요청별 baggage 헤더 + journal delta → InvocationOutcome.httpExchanges
- ResponseDtoIndexer(2.5) → consumedFields
- 통합 테스트: EXPRESS 201 path에서 CapturedHttpCall + baggagePropagated=true → commit

### Task E: testlib — HttpMockClient 빌더 + wiremock 어댑터
- stub 빌더 API + noop 갱신 + WireMockHttpMockAdapter(admin REST, metadata로 scope 제거)
- 단위 테스트: 로컬 HttpServer로 admin 호출 형태 검증 → commit

### Task F: generator — http-mock-composer + 병렬 안전
- HttpMockComposer: 스텁 라인 합성(consumedFields 투영, baggage 매칭), 템플릿 mocks 슬롯
- propagation 없으면 serialRequired + `@Execution(SAME_THREAD)`
- 골든/결정성 테스트 갱신 → commit

### Task G: E2E + 문서 + push
- compose: app에 otel agent(volume) + EXTERNAL_INVENTORY_URL=wiremock
- run-e2e.sh: --external-stubs, --sut-env; runner env HTTP_MOCK_ADAPTER=wiremock
- N+α 테스트 전부 PASS, progress/2-*.md + decisions + README, push
