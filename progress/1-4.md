# 1.4 — MyBatis 발행 SQL 캡처

## 진행 내용

- `SqlLogParser`(통합 파서): Hibernate(`org.hibernate.SQL` + bind)와
  MyBatis(`==>  Preparing:` / `==> Parameters:` — `값(타입)` 토큰) 형식을
  한 번의 스캔으로 발행 순서 보존 파싱
- SutProcess: 인덱싱된 mapper namespace를 TRACE 레벨로 `SPRING_APPLICATION_JSON`에
  동적 주입 — 외부 프로세스 + env 주입 원칙 유지
- docs/11의 ProxyDataSource/Interceptor(in-process 부착)는 보류:
  동적 SQL의 "실제 평가된 형태"는 MyBatis 로그로도 동일하게 확보됨

## 검수

- 파서 단위 테스트 5건 (Hibernate/MyBatis/null 파라미터/혼합 순서/빈 로그)
- 실 SUT 통합: search 200 path에서 orders SELECT(동적 where 평가 완료형) 캡처 확인
