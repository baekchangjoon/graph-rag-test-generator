# 1.2 — path constraint (콘콜릭 대체: 정적 추출)

## 진행 내용

- `ConstraintExtractor`: Spoon으로 handler 메서드의 if/삼항 조건식과 라인 범위를
  수집, path의 도달 분기 라인과 매칭해 `ExploredPath.constraints`로 첨부
- JDart(콘콜릭) 엔진은 의식적 보류 — 외부 프로세스 분석 환경과의 구조적 불일치
  + roadmap 09의 위험 대응("Phase 1은 fuzzer 위주")
  근거와 복귀 조건: `docs/decisions/explorer-engines.md`
