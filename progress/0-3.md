# 0.3 — testlib

## 진행 내용

- `api/`: TestScope(unique testId, cleanup idempotent), JdbcHelper(lazy 연결,
  INSERT/DELETE 시 대시보드 이벤트), RestAssuredHelper(baseUri + baggage 헤더),
  HttpMockClient/SocketMockClient/AuthClient 인터페이스
- `spi/`: Env(주입 가능), Adapters(ServiceLoader + 환경변수 선택),
  5종 어댑터 SPI
- `adapter/`: plain-jdbc(기본), noop http/socket/auth,
  dashboard http(fire-and-forget, 500ms timeout) / noop(DASHBOARD_URL 미설정 시)
- fail-fast: APP_BASE_URI, JDBC_URL 누락 시 IllegalStateException
