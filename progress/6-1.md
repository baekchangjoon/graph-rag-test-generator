# 6.1 — 분산 그래프 스토어 검토 + 파티션 샤드 스토어

- 검토 결과: Neo4j 보류, 파티션 샤드 파일 스토어 채택
  (`docs/decisions/graph-store-phase6.md` — 후보 비교·복귀 조건 기록)
- `GraphPartitioner`: 파티션 키 = 핸들러 패키지; 변경 파일 → 더티 파티션 매핑
  (매핑 불가 변경은 전체 더티의 보수적 규칙)
- `PartitionedGraphStore implements GraphStore`: global.json(전역 사실) +
  `partitions/<패키지>.json` 샤드 저장/병합 로드, 재저장 시 stale 샤드 제거
- 호환: BuilderCli는 graph.json(병합본)과 샤드를 함께 저장 → 도구 2 무수정
- 검수: 단위 8건 GREEN (파티셔너 5 + 스토어 3: 샤딩·라운드트립·stale 교체)
- Phase 4/5는 사용자 지시로 홀딩, 6.1·6.2를 선행 (docs/10의 6a 단계에 해당)
