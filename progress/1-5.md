# 1.5 — 다중 path → 다중 테스트 합성

## 진행 내용

- `GenerationRequest.pathId` 생략 시 endpoint 전 path 생성, path당 클래스 1개
  (`<base>_<S{status}_{n}>`)
- **status-aware 픽스처**: 2xx path만 사전 INSERT 합성. 4xx path는 "사전 데이터
  부재"가 재현 조건 — 치환 변수(testId-unique)만 유지해 404를 결정적으로 재현
- 픽스처 강화: SERIAL/IDENTITY PK 컬럼 INSERT 제외, FK 부모 행 재귀 seed
  (부모 먼저 INSERT, 자식 먼저 DELETE)
- warnings에 path의 validation_warnings 전달

## 검수

- composer/generator 단위 테스트 15건 (골든 파일 + 결정성 포함) GREEN
- E2E: 12 path → 12 클래스 → **12/12 통과**
